# Zero-Friction Transformation Protocol

A web-based fitness and nutrition protocol designed for lazy software engineers. This interactive tool helps you optimize your health inputs without the hassle of cooking or intense workouts.

## Features

- **Dynamic BMI Calculator**: Input your weight, height, and age to get real-time BMI status and health insights.
- **Caloric Analysis**: Visualize projected caloric burn vs. intake based on your sedentary lifestyle.
- **Nutrition Guidance**: AI-powered takeout optimization using Google Gemini API.
- **Workout Protocol**: Simple, low-effort movement routines integrated into your coding workflow.
- **Daily Schedule**: A low-stress daily routine for hydration, meals, and exercise.
- **Bio-Mechanics Debugger**: AI-assisted form correction for exercises.

## Technologies Used

- **HTML5**: Structure and content
- **CSS3**: Styling with Tailwind CSS
- **JavaScript**: Interactivity and logic
- **Chart.js**: Data visualization for charts
- **Plotly.js**: Scatter plot for nutrition matrix
- **Marked.js**: Markdown parsing for AI responses
- **Google Gemini API**: AI-powered suggestions (requires API key)

## How to Use

1. **Clone or Download**: Get the project files to your local machine.
2. **Open in Browser**: Simply open `index.html` in any modern web browser.
3. **Configure**: Enter your weight, height, and age in the System Configuration section and click "Run System Diagnostics".
4. **Explore Sections**:
   - View your BMI gauge and caloric insights.
   - Use the AI modules by pasting your Gemini API key in the navigation bar.
   - Follow the workout and nutrition protocols.
5. **AI Features**: For the Takeout Refactor Tool and Bio-Mechanics Debugger, provide a valid Google Gemini API key.

## Setup

No server required! This is a client-side web application. Just ensure you have an internet connection for the external libraries and API calls.

- **API Key**: Obtain a Google Gemini API key from [Google AI Studio](https://makersuite.google.com/app/apikey) and paste it into the input field in the navigation bar.
